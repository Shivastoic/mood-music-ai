# 🎵 Mood-Based YouTube Song Recommender

A modern, sleek web app built with **Next.js**, **Tailwind CSS**, and **Google Gemini AI** that recommends songs based on your mood.  
The app fetches songs from **YouTube** with thumbnails, singer details, and an embedded player — all wrapped in a glowing, modern UI.

---

## ✨ Features
- 🎯 **Mood-based song suggestions** using Google Gemini API
- 🎬 **YouTube integration** to fetch videos & metadata
- 🎨 **Modern UI** with glowing gradients and responsive design
- 📱 **Mobile-friendly** with adaptive play button behavior
- ▶️ **Embedded YouTube player** without extra clutter
- ⚡ Fast, smooth animations and hover effects

---

## 🛠 Tech Stack
- **Framework**: [Next.js](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **AI**: [Google Gemini API](https://ai.google.dev/)
- **Video Data**: [YouTube Data API v3](https://developers.google.com/youtube/v3)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
